Four AI-generated PNG studies, not photographs of a real building and not calibrated views of a verified 3D model. Native dimensions 1536x1024, no upscale. Requested high; provider reported low for01/03 and medium for02/04. Do not claim maximum quality or 4K.

Recommended first test: upload ONLY01-master.png into Marble Create, 2D image mode. Use marble-prompt.txt if a text field is available alongside image input. Otherwise the image is the primary input; do not assume an absent control. Inspect generated panorama before further processing when the UI permits. This isolates the approved appearance without contradictory extra views.
